# LibTV Canvas Boost

给 liblib.tv / iblib.tv 的画布加一堆顺手的小功能。装个油猴脚本就行，不用改网站。

## 功能

### 画布与性能
- **FPS 面板** —— 右下角实时显示帧率、缩放比例、节点数，可拖动
- **性能模式**（T）—— 节点少特效，画布更流畅
- **隐藏图片**（H）/ **隐藏连线**（L）/ **隐藏网格**（G）—— 节点多卡顿时一键减负
- **专注模式**（X）—— 藏掉侧边栏和顶栏，只留画布
- **流动光效** —— 画布连线上的流光动画

### 整理与浏览
- **链路高亮**（C）—— 点一个节点，它的上下游整条链自动高亮，其它变暗；再点空白处取消
- **节点搜索**（F）—— 按文字找节点，快速跳过去
- **标签系统** —— 给节点打标签，四层结构：库 → 分类 → 分组 → 标签，随时筛出来看
- **直角连线**（R）—— 连线改成电路板风格的直角走线，自动绕开节点
- **帮助速查**（?）—— 快捷键小卡片钉在角落

### 积分换算
- **积分旁边直接显示人民币估值** —— 顶栏余额、每个节点的生成消耗旁边，都标出大概值多少钱
- **会员折扣也能换** —— 显示「现价 / 原价」的折扣节点，两个数都给你换算
- **单价自己填** —— 不同会员档位积分单价不一样，在设置里填「1 积分 = 多少元」，改完立即生效
- **一键开关** —— 不想要了，设置里关掉「积分换算」

### AI 提示词工具
- **提示词面板**（P）—— 浮动按钮打开，右键可切换按钮样式
- **内置润色 / 扩写 / 缩写 / 中英互译** —— 选个策略点一下就出结果，原文可对照
- **自定义模型** —— DeepSeek、本地 Llama、任何兼容的网关都能接，接口地址和模型名自己填
- **提示词模板库** —— 常用提示词存起来，下次直接用

### 其它
- **画布主题** —— 18 套配色一键换
- **账号切换** —— 多账号保存 / 切换 / 刷新，不用来回退出登录
- **内容包** —— 标签库、提示词、设置整体导出成 JSON，换电脑或分享给同事直接导入
- **设置面板** —— 所有开关集中管理，油猴菜单也能打开
