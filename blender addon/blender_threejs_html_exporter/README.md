# Three.js 独立 HTML 导出器 2.11.0

Blender 插件，将场景导出为单个 HTML 文件，内嵌 GLB 模型与 Three.js 查看器。插件与查看器界面均已汉化。

开发要点与踩坑记录见 [DEVELOPMENT.md](DEVELOPMENT.md)。

## 环境要求

- Blender 3.6 及以上
- 支持 WebGL 的现代浏览器
- 查看导出文件时默认无需联网（内嵌运行库）；关闭该选项才需要访问 jsDelivr

模型内嵌在 HTML 中；默认同时内嵌 Three.js 运行库（导出时下载一次），打开文件无需联网。若关闭“内嵌运行库”或下载失败，查看器从 jsDelivr 加载 Three.js 0.160.0。

## 产物体积

GLB 与运行库均以 **brotli/gzip 压缩后 base64 内嵌**，浏览器用原生 `DecompressionStream` 解压（不引入任何解码库）。实测效果：

| 场景 | 未压缩 base64 | 压缩后 |
|---|---|---|
| 默认立方体 | 2.0 MB | **0.95 MB** |
| 5×96 段球体（GLB 7.4MB） | 11.9 MB | **1.2 MB** |

解压后由动态 `importmap` 注入 blob URL，三者（运行库 / GLB / 查看器源码）共用同一套动态注入机制。运行时无 `DecompressionStream` 时，GLB 回退为未压缩 base64，运行库回退到 CDN。

## 安装

1. 将 `blender_threejs_html_exporter` 目录放入 Blender 插件目录。
2. 打开 `编辑 > 偏好设置 > 插件`。
3. 启用 **Three.js 独立 HTML 导出器**。

## 导出

打开 `文件 > 导出 > Three.js 独立 HTML (.html)`。

可设置：导出范围（全部/可见/选中）、初始明暗主题、边线与边线角度、自动旋转、动画模式、帧范围限制与自动播放、使用场景相机机位、导出场景灯光与灯光强度倍率、内嵌运行库（离线）、纹理压缩（自动/JPEG/WebP）、环境光照明、导出世界环境、环境光强度、SSAO 及遮蔽强度。

## 查看器

- 顶部两组浮动工具栏：左侧视图组（正视/顶视/等轴测/适配/全屏），右侧开关组（边线/旋转/结构/主题/投影/截图），SVG 图标
- 场景结构树：展开/折叠、按名称过滤、点击名称聚焦对象、节点显隐
- 动画播放/暂停/停止、倍速（0.5x/1x/2x）、拖动进度条
- 深色/浅色主题、透视/正交投影、加载遮罩
- 基于图像的环境光照：默认将 Blender 世界渲染为低分辨率全景图嵌入（512×256 JPEG，几十 KB），查看器光照与 Blender 一致；无世界或渲染失败时回退内置 `RoomEnvironment`；金属等 PBR 材质显示更准确，可在导出时关闭
- **环境光强度**：查看器反射强度（材质 `envMapIntensity`）可调，默认 2.0；配合 Blender 世界的 `Strength` 一起控制环境亮度
- **环境光遮蔽 (SSAO)**：实时屏幕空间遮蔽后处理，增强接触阴影与层次感；查看器内用遮蔽按钮或 `A` 键开关，强度在导出选项中设置
- 键盘快捷键：`1` 正视、`3` 等轴测、`7` 顶视、`F` 适配、`E` 边线、`空格` 播放/暂停
- 窄屏（≤720px）自动切换为纯图标按钮，动画栏全宽

## 灯光

默认导出 Blender 场景灯光（点光/日射/聚光/面光）进内嵌 GLB，查看器直接使用，光照与 Blender 基本一致；无灯光或关闭该选项时回退内置三点光。

- 日射光导出为平行光（direction），点光/聚光导出为点光/聚光（position + distance/decay）。
- 强度采用 glTF 规范的物理单位（点/聚光 candela，日射光 lux），查看器用 Three 的物理光照模式，两侧单位一致，无需换算。
- 如觉得偏亮/偏暗，用**灯光强度倍率**（默认 1.0）整体缩放；数值选项支持 0–4 沿滑块。

## 初始机位

默认以**场景活动相机的角度、距离与视角**作为查看器初始机位（含透视/正交与焦距），打开即所见即所得，便于工程交付固定机位。无相机时自动适配视图；可在导出选项中关闭。

## 动画

默认动画模式为 **合并当前动作**。其他模式取决于 Blender glTF 导出器与 Blender 版本。仅当 GLB 数据包含动画时才显示动画控件。

## 限制

- 关闭内嵌运行库时，查看器需访问 `cdn.jsdelivr.net`。
- 内嵌运行库默认使用磁盘缓存（`<Blender 用户目录>/cache/threejs_html_exporter/`）：首次导出需下载一次（约几秒），之后即时命中。
- 极老旧浏览器（无 `DecompressionStream`）无法享受压缩收益：GLB 回退未压缩 base64，运行库回退 CDN。
- GLB 压缩后仍以 base64 内嵌，大场景解码加载需要额外浏览器内存。
- 边线会复制几何边数据；大型或高面数模型建议默认关闭边线，首次启用时才会创建。
- 仅支持 WebP 纹理压缩。Draco 网格压缩未实现（需查看器额外加载 wasm 解码器，与离线内嵌的 data: URL 方案冲突）。
- 可用场景规模受浏览器与 GPU 限制。

## 侧边栏

3D 视图 `N` 面板的 **Three.js** 标签提供快捷工作流：输出路径、导出后自动打开、全部导出参数（几何/外观与光照/动画/输出选项四个可折叠分区，未启用的相关参数自动置灰），以及一键导出按钮（跳过文件对话框）。

参数保存在场景中，随 .blend 保存，便于反复调参导出。文件菜单中的导出对话框入口保留，两套流程共存。

## 冒烟测试

在本目录执行（路径按本机安装位置调整）：

```powershell
# --python-exit-code 1 必加：否则 Blender 吞掉脚本异常，测试失败也返回 0
& "D:\Blender\stable\blender\blender.exe" --background --factory-startup --python-exit-code 1 --python tests/smoke_test.py
```

成功时输出 `SMOKE_TEST_OK`。

测试导出带动画的立方体，并校验内嵌 GLB 的网格与动画数据。
